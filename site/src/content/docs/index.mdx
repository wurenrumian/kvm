## 这门课讲什么

面向有 Linux 基础、想把 KVM 从「会用」到「讲得清」的工程师。围绕一条主线展开：
**从一台裸机到能生产可用的虚拟化平台**，每一层（CPU、内存、I/O、存储、网络、迁移、
安全、性能）都讲清楚「为什么这么设计」和「怎么调、怎么排错」。

每个模块统一结构：**学习目标 → 核心概念 → 原理拆解 → 动手实验 → 排错指南 → 练习 → 延伸阅读**。

<Aside type="tip" title="先跑通，再深挖">
建议先做完模块 02，让虚拟机真正跑起来，有体感后再回头看模块 03 的原理。
配套的 <a href="https://github.com/wurenrumian/kvm/tree/main/scripts">演示脚本</a> 可以直接把核心概念跑一遍。
</Aside>

## 快速开始

环境基线为 Fedora 44 / Intel VT-x。先装工具链，再跑演示：

```bash
git clone https://github.com/wurenrumian/kvm.git
cd kvm

# 1) 环境自检（只读）
./scripts/01-check-env.sh

# 2) 安装 QEMU/libvirt（需要 sudo，装完重新登录）
sudo ./scripts/02-setup-toolchain.sh

# 3) 下载演示镜像（独立脚本，约 60MB）
./scripts/00-download-iso.sh

# 4) 一键跑全部演示
./scripts/run-all.sh --no-install
```

> 演示脚本与课程模块一一对应，详见仓库的 `scripts/README.md`。
